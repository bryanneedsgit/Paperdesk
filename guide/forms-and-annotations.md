# Forms And Annotations

## Forms

Fillable form fields are highlighted directly on the page. Click a field to type into it, toggle a checkbox, pick a radio option, or choose from a dropdown — exactly where the field sits in the document.

The Forms tools panel mirrors the same values, so you can also:

- Review every detected AcroForm field in one list.
- Fill or change form values before export.
- Import and export form data as JSON.
- Choose whether fields should be flattened on export.

On-page edits and panel edits stay in sync. Unsupported or advanced field types (such as signature fields) may be left unchanged.

## Annotations

Open the Annotations tools panel or use the annotation controls in the viewer toolbar.

Paperdesk supports exportable annotations such as:

- Text boxes.
- Highlights.
- Shapes.
- Pen marks.
- Signatures.

Annotation edits can be undone and redone with workspace history.

## Text Boxes

Use the text-box tool before placing a text box. After selecting the tool, right-click on the page to place the text box. When you start typing, the default placeholder text is cleared automatically.

Selected text boxes can be deleted with the Delete action.

## Signatures

Add a signature image in the Annotations tools panel. Once added, the signature can be placed as an annotation and exported with the PDF.

## Export Behavior

Annotations are overlays. They are preserved in the workspace and burned into the exported PDF output.
