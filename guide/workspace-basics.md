# Workspace Basics

## Open PDFs

Open a PDF to create a workspace. Paperdesk loads local PDF files directly on your device.

You can also drag and drop PDF files into the app:

- If no workspace is open, dropped PDFs create a new workspace.
- If a workspace is already open, dropped PDFs are added to the current workspace.

## Add PDFs

Use the Document tools panel on the right to add more PDFs to the current workspace. Added files appear as sources, and their pages are appended to the workspace.

The source list shows:

- The PDF file name.
- How many pages from that source are currently included.
- The original total page count.

## Recent Files

Recent files appear in the Document tools panel when recent-file memory is enabled. Select a recent file to reopen it.

You can clear recent files from Settings.

## Autosave And Recovery

Paperdesk can autosave workspace metadata locally. Recovery helps restore page order, selections, edits, form settings, formatter settings, and annotations after an interruption.

If a source PDF cannot be found during recovery, Paperdesk asks you to relink the missing file.

## Privacy

Paperdesk is designed for local work:

- PDF processing happens on your device.
- Files are not uploaded.
- No cloud sync is built in.
- OCR is not included.
