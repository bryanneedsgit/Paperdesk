# Keyboard Shortcuts

Paperdesk supports a small set of keyboard shortcuts for common workspace actions.

| Action                                       | Shortcut                       |
| -------------------------------------------- | ------------------------------ |
| Open PDF                                     | Cmd/Ctrl O                     |
| Export PDF                                   | Cmd/Ctrl S                     |
| Undo                                         | Cmd/Ctrl Z                     |
| Redo                                         | Cmd/Ctrl Shift Z or Cmd/Ctrl Y |
| Zoom in                                      | Cmd/Ctrl +                     |
| Zoom out                                     | Cmd/Ctrl -                     |
| Delete selected pages or selected annotation | Delete or Backspace            |
| Previous page                                | Arrow Up                       |
| Next page                                    | Arrow Down                     |
| Clear page selection                         | Escape                         |
| Select all pages in the thumbnail sidebar    | Cmd/Ctrl A                     |

Cmd/Ctrl M is not used as a shortcut.
