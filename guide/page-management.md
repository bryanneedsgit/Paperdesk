# Page Management

## Thumbnail Sidebar

The left sidebar shows workspace pages as thumbnails. Use it to inspect the full document structure and select pages for batch actions.

You can collapse or expand the left sidebar from the top toolbar.

## Select Pages

Select pages in the thumbnail sidebar before deleting, rotating, moving, or exporting selected pages.

Supported selection actions include:

- Select a page.
- Toggle page selection.
- Select all pages when the thumbnail sidebar is focused.
- Clear selection with Escape.

## Reorder Pages

Drag thumbnails to rearrange pages. When multiple pages are selected, dragging one selected thumbnail moves the selected group together.

Page rearranging is non-destructive. The source PDF bytes stay unchanged until you export a new PDF.

## Delete Pages

Delete selected pages from the workspace with the sidebar controls or Delete/Backspace. Deleted pages are removed from the exported result but do not modify the original PDF files.

Large delete operations ask for confirmation.

## Rotate Pages

Rotate selected pages left or right from the viewer toolbar. Rotation is applied to the exported PDF.

## Navigate Pages

Use the viewer toolbar to:

- Go to the previous page.
- Go to the next page.
- Type a page number to jump directly to that page.

The status bar shows the current page number, total page count, zoom level, active source file, and whether the workspace has edits.
