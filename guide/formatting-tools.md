# Formatting Tools

Open the Formatter tools panel from the right sidebar to apply page-level formatting.

## Page Numbers

Add page numbers to exported pages. You can configure page number placement and start number.

Formatting can apply to all pages or only selected pages.

## Headers And Footers

Add header and footer text as exportable overlays. These overlays appear in the preview and are burned into the exported PDF.

## Watermarks

Add watermark text to pages. Watermark text and opacity are grouped together in the Formatter panel so the text and strength can be adjusted in one place.

## Crop Margins

Use crop margin settings to change the visible page area in the exported PDF.

## Resize Preview

Resize changes update the workspace preview in real time so you can see layout changes before exporting.

## Insert Pages

The Formatter panel can insert:

- Blank pages.
- Cover pages.

Inserted pages become part of the workspace and export with the rest of the document.

## Font Choice

Formatter settings support font selection for overlay text such as headers, footers, page numbers, and watermarks.
