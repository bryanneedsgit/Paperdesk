# Security Policy

## Supported versions

Security fixes are applied to the latest code on the `main` branch.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting for this repository when it is available. Otherwise, contact the maintainer through the GitHub profile at [@bryanneedsgit](https://github.com/bryanneedsgit) before sharing sensitive details.

Include the affected version or commit, reproduction steps, impact, and any suggested mitigation. Please allow reasonable time for investigation and a fix before public disclosure.
